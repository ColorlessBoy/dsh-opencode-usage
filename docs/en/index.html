Provider-aware

Shown only when the current model's provider baseURL points at OpenCode Zen Go; switching to any other provider hides it automatically.

Remaining only

The upstream API reports used percent; the host normalizes it to remaining, consistently in the pill, the panel and the accessible name.

Click to expand

Same panel skin as the built-in Token usage: each window's remaining share and reset countdown, with the tightest window in the title.

Keys stay on the host

The browser only calls same-origin /api/opencode-usage; the API key is resolved by the host credentials service via apiKeyEnv.

Install

As a bundle in the web profile. The repo ships a runnable lib/, so install needs no build approval:

dsh plugin --profile web add github:ColorlessBoy/dsh-opencode-usage

Restart dsh web and refresh the page. To verify composition without booting: dsh --profile web --dump-config should show # == dsh-opencode-usage.

Orientation

No route takeover, no key copying, no new settings page or floating card: it reuses your existing llm-pi-ai config and credentials, and adds one quiet pill.

FAQ

How do I see my OpenCode Go quota in DeepSeek Harness?

Install the plugin: the composer stats line gains a battery pill with the 5-hour rolling, weekly and monthly remaining shares; open it for each window's reset countdown.

Does it show quota for other providers?

No. It keys off the current model's provider baseURL and only appears for routes that point at opencode.ai/zen/go; other providers hide it automatically.

Do I need to configure an API key or endpoint?

No. The host half reads the provider already configured in llm-pi-ai (baseURL / apiKeyEnv); the API key is resolved by the credentials service and never reaches the browser.

How do I install it, and do I need to restart?

Run the install command, then restart dsh web and refresh the page. The repo ships a prebuilt lib/, so no build approval is required.

How often does the quota refresh?

The page polls the same-origin endpoint every 15 seconds; the host caches successful reads for 30 seconds and failures for 10 seconds and merges concurrent upstream requests.

Does it support only OpenCode Go?

Yes. It reads the official OpenCode Go quota API (5-hour rolling, weekly, monthly) and nothing else.
